# Malware Behavior to MITRE ATT&CK Technique Mapper

A Python-based command-line tool that analyzes observed malware behaviors and maps them to corresponding MITRE ATT&CK techniques using rule-based logic.

This project is implemented as a **Week 14 Minimum Viable Product (MVP)** for a cybersecurity programming course.

---

## Project Overview

Malware analysis tools often produce raw behavior data that must be manually interpreted and aligned with the MITRE ATT&CK framework.  
This tool automates that process by:

- Reading structured JSON malware behavior data
- Applying rule-based mappings to ATT&CK techniques
- Producing a standardized JSON report for analysis and reporting
